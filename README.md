# NumPy-Student-Marks-Analysis

## Description
This project uses Python and NumPy to analyze student marks and calculate important statistical values.

## Objective
To learn how NumPy performs numerical calculations efficiently.

## Tools Used
- Python
- NumPy
- Jupyter Notebook

## Concepts Used
- NumPy Arrays
- Mean
- Median
- Maximum
- Minimum
- Standard Deviation

## Implementation
Student marks are stored in a NumPy array. NumPy functions are used to calculate the mean, median, maximum, minimum, and standard deviation.

## Results
- Mean: 78.8
- Median: 79.0
- Maximum Mark: 95
- Minimum Mark: 60
- Standard Deviation: 10.29

## Conclusion
This project demonstrates how NumPy can be used to perform statistical analysis of student marks quickly and easily.
